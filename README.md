# Piscine 42

Ce dépôt contient mes travaux réalisés durant la Piscine de l’école 42 (Paris).  
Il regroupe les différents exercices, rushs et projets quotidiens effectués au cours des 4 semaines intensives.

---

## Organisation du dépôt

- **C00 → C13** : séries d’exercices C (bases, pointeurs, tableaux, fonctions, etc.)  
- **Shell00 / Shell01** : exercices d’introduction au shell et scripts.  
- **Rush00 / Rush01 / …** : projets de groupe du week-end.  
- **Exam00 / Exam01 / …** : examens blancs ou officiels de la Piscine.  

---

## Objectifs pédagogiques

- Découvrir le langage **C** et ses fondations (syntaxe, compilation, gestion mémoire).  
- Apprendre à travailler avec le **shell Unix** et les outils de développement.  
- Développer la rigueur avec la **Norminette** (norme de code 42).  
- Apprendre le travail en **pair programming** et en **projets de groupe**.  
- Se préparer aux projets du tronc commun (libft, get_next_line, printf, etc.).
